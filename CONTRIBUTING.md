# Contributing

Add something you have done yourself.

## A note

Put it in `docs/`. Explain one idea, what it is for, and the AWS name for it. If you know the Azure equivalent, add one line for people crossing over. Skip console click-paths that will rot; link the lab that uses the idea.

## A lab

Create `labs/NN-short-name/README.md` with:

- **Goal** — one sentence
- **You need** — account, region, and anything earlier labs assumed
- **Steps** — what you actually did
- **Check** — how you know it worked
- **Clean up** — every resource to delete
- **What it cost** — Free Tier, or the rough charge if it was not

Update the path table in the root README when you add a lab.

## Leave out

Keys, account IDs, passwords, `.pem` files, Terraform state, and screenshots that show a secret or an account number.
